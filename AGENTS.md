# AGENTS.md – Zombie Survival Video Agent

Purpose: turn a script/premise into a **realistic, tense, retention-optimised** visual plan for zombie-survival videos in a flat 2D paper-cutout style.

**Start by reading `SKILL.md`**, then the files in `references/` and `templates/` as it directs.

Key points:
- Look is locked; scenes, devices, overlays and sound are designed fresh per script.
- "Real" = consistent rules + resource ledger + diegetic overlays (CCTV/radio/HUD) + sound + believable people.
- Use the tension engine; rotate devices; never repeat back-to-back.
- Restrained horror only; survival tips must be accurate and safe (`references/content-rules.md`).

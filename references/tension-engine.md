# Tension Engine – keep viewers hooked (no fixed plan)

## 1. Hook (0–3 s) – choose ONE per script
- **Stakes in a number:** "3 litres of water. 4 people. 2 days."
- **Cold open mid-danger** → cut to "12 hours earlier".
- **Impossible choice** on screen ("Door A / Door B").
- **Silhouette in fog** with a sound (scratch, groan) and nothing else.
- **Rule broken** ("Rule #1 was silence. Someone just dropped a can.")
- **Countdown / battery 3%.**
- **Found note / last radio message.**
Hook = visual first, text second. No logo/title card first.

## 2. Device menu (mix freely; never the same device twice in a row)
| Device | When |
|---|---|
| **Countdown / clock** | time limits (sunset, battery, door holds) |
| **Noise ring + heads turn** | a sound mistake |
| **Peek shot** (keyhole/gap/blinds) | unseen threat |
| **Silhouette reveal** (black shape → colour pop on light) | introduce a creature/person |
| **Cutaway floor-plan** | spatial dread (they above, horde below) |
| **CCTV cut** | viewer knows more than characters |
| **Inventory HUD tick-down** | resource pressure |
| **Map route draws** | journeys & risk |
| **Split-screen (safe vs outside)** | contrast, parallel action |
| **Decision fork** (A/B with timer) | engagement; poll in comments |
| **Domino chain** | cause→effect of a mistake |
| **Rule card** | teaching + world consistency |
| **Mistake autopsy** ("what went wrong") | "would you survive?" learning |
| **Sound-led blackout** (screen black, only audio) | peak fear |
| **Slow-reveal pan** (panning across a horde) | scale shock |
| **Time-lapse** (base-building, days passing) | progress/exhaustion |
| **Flashback/diary** | emotional depth |
| **Radio voice over map** | exposition without talking heads |
| **Fake-out** (safe → false alarm → real danger) | rhythm control (use sparingly) |
| **Quiet human beat** (shared food, music box) | contrast, empathy |

## 3. Dread curve (plan per video)
Calm → unease → first threat → escape → relief (false safety) → complication → bigger threat → sacrifice/choice → climax → quiet aftermath → **hook for next**.
- Alternate **tension and release**; each peak higher than the last.
- Use **silence** before the scare; **quick cuts** during; **long hold** after.
- Don't spend all scares early; **save the biggest reveal for 70–85%**.

## 4. Anti-repetition rules
- No same device in consecutive beats; no same background + shot size twice in a row.
- Pattern interrupt every 5–8 s (device, palette, scale, motion style, sound).
- Over any 30 s: ≥ 3 shot sizes, ≥ 2 palettes/light states, ≥ 2 motion types, at least 1 quiet moment.
- Don't use more than **2 jump scares per minute**; replace with **dread** (implication > shock).
- Don't open and close two different videos the same way.

## 5. Audience-investment tools
- **Attach people:** give each survivor a name, item, habit, flaw, and one small human moment in the first 20 s.
- **Open loops:** plant a question ("Who left the door open?") and answer 10–40 s later; or never until the series' next episode.
- **Dramatic irony:** show the threat to the viewer before the characters (CCTV/silhouette).
- **Choice & comment bait:** end with "What would you do?" + two options; pin results in next episode.
- **Series hooks:** cliffhanger image, mysterious final line, "Day 8 → ???".
- **Rewatch value:** hide small details (a sign, a shadow, a number) that pay off later.

## 6. Emotional range
Fear · dread · hope · grief · humour (dark, light touch) · camaraderie · guilt. Humour only in release beats.

## 7. Retention checkpoints
- 0–3 s hook · 10 s first stake clarified · 25–35 s first escalation · 50–60% a twist/loss · 80% biggest set-piece · last 10% resolution + hook.
- Check: Does every beat either **raise stakes, reveal, or deepen character**? If not, cut.

## 8. Variety self-test
List the device used per beat; if neighbours repeat or it reads like a template, redesign.

# From Script to Visual – Method

## 1. Parse
- Central question (will they make it? what would you do? what is the rule?).
- World: place, time, weather, zombie rulebook, survivors, ledger start.
- Tag each sentence: *place · time · characters · action · emotion · threat level (0–5) · info (fact/rule/clue) · sound*.

## 2. World Sheet (fill first; see template)
Lock rules, cast, supplies, map, clock **before** beats. If script is vague, choose conservative defaults (walkers, sound-based, bite infection, head-trauma weakness) and note assumptions.

## 3. Beat-split
Split at change of place/time, threat level, speaker, info, decision, or sound.
Target 2–8 s per beat; shorter during chase. Mark **hero beats** (reveal, loss, choice, escape).
Threat level (0 calm → 5 peak) plotted across beats = the dread curve.

## 4. Map to visuals
| Script cue | Visual options (choose per context; don't default) |
|---|---|
| Sound mentioned | noise ring, head-turns, cut to threat silhouette, ambience-only shot |
| Number/stat | HUD tick-down, rule card, counter |
| Time pressure | countdown, sunset bar, battery % |
| Decision | fork with timer, split-screen outcomes |
| Danger unseen | peek shot, CCTV, silhouette in fog |
| Danger seen | wide with depth layers, then close on face |
| Safe place | warm amber light, close framing, quiet detail |
| Loss/grief | held shot, muted palette, diary/photo, minimal sound |
| Planning/route | map draw, cutaway floor plan |
| Fact/tip | rule card + diagram + calm voice |
| Mistake | domino chain, red circle, slow-mo |

## 5. Design each beat
Use the beat card (`templates/shot_list_template.md`). Always include: threat level, device, light source, camera, characters/creatures, props, motion, overlays, sound, ledger update, on-screen text, transition, prompts.

## 6. Assets list
Unique backgrounds, character variants (injured/dirty/day-N), zombie types, props, overlays/HUD, text cards → generate once & reuse for consistency.

## 7. Timing
With audio: align cuts to word timestamps & sound hits. Without audio: 2.3–2.8 English words/sec (≈ 140–165 wpm; slower in dread, faster in action); leave **silent beats** (0.5–2 s) deliberately.

## 8. QA checklist
- [ ] Rulebook obeyed every beat; ledger numbers consistent
- [ ] Continuity (injuries, light, props, weather, day/time)
- [ ] Dread curve has peaks + releases; biggest reveal ~70–85%
- [ ] Device log has no neighbour repeats; ≤ 2 jump scares/min
- [ ] Overlays have in-world logic (battery, signal, timestamps)
- [ ] Sound plan for every beat (including deliberate silence)
- [ ] Survival facts accurate & safe; no weapon/explosive/harm instructions
- [ ] No gore; respectful depiction; text spelling & grammar (English); safe margins
- [ ] Hook in 3 s; ending hook/cliffhanger present

# Realism Layer – diegetic overlays & imperfections

Goal: make flat art feel like **found footage / lived experience**. Use per script – don't use every item.

## Diegetic overlays (pick purposefully)
| Overlay | Looks like | Use for |
|---|---|---|
| **CCTV frame** | desaturated, scanlines, corner camera ID, timestamp, REC dot, slight fisheye, low fps | reveals threat unseen by survivors |
| **Bodycam/phone cam** | rounded frame, REC dot, battery %, shake, lens smudge | first-person tension |
| **Radio/walkie** | waveform bar, static noise, callsign, subtitle in monospace | exposition, hope, betrayal |
| **News ticker / breaking news** | lower-third band, red "LIVE" tag | outbreak, world context |
| **Phone UI** | cracked screen, "No service", battery 4%, last text | personal stakes |
| **Map** | hand-drawn/printed map, marker route drawing itself, X marks, distance | journeys, supply runs |
| **Inventory HUD** | icon slots with counts; red flash when low | resource tension |
| **Meters** | thin bars: water, food, stamina, noise, health | pressure |
| **Noise ring** | expanding circle from source; zombie heads turn into it | consequence of sound |
| **Clock/Day counter** | "DAY 9 · 17:42", sunset bar | time pressure |
| **Diary/notes** | torn paper, handwriting, coffee stain, crossed-out lines | intimacy, backstory |
| **Floor plan/cutaway** | building cross-section, zombies below, survivors above | spatial suspense |
| **Thermal/night-vision** (rare) | green/orange mono palette | set-piece |

## Camera imperfections (add subtly)
- Handheld drift, micro-shake on footsteps, **breath fog** on cold nights, lens dirt/raindrops, vignette, film-grain texture, occasional focus pull (blur layers), **light leaks** from torches, flash-frame on lightning.
- Cut the camera to **where the character is looking** (peek, keyhole, through blinds, over shoulder, mirror, window reflection).
- Use **depth fog layers** so zombies emerge from mist silhouettes.

## Environmental storytelling (props that tell time & history)
Barricaded doors with scratch marks · missing-person flyers · abandoned cars with doors open · graffiti rule lists ("DON'T GO TO THE HOSPITAL") · half-eaten meal on a table (non-gory) · dead phone chargers · empty shelves · calendar with crossed days · child's drawing · dried flowers · water stains · dust on piano.

## Sound-linked visuals
Every overlay change has a sound: radio click, camera whirr, battery warning beep, notification buzz, pen scratch, zip.

## Realism check
- Do overlays obey the same rules as the world (battery drains, signal weak, timestamps advance)?
- Are numbers consistent with the ledger?
- Is there a reason for this camera to exist (CCTV installed, phone recording)?

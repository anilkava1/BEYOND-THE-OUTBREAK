# Video Formats (pick or blend per script; design fresh each time)

| Format | Structure idea | Visual notes |
|---|---|---|
| **Story / Short film** | one escape or one night; 3-act dread curve | strong light design, minimal HUD, character beats |
| **Day-by-Day series** | Day counter, ledger shrinks, relationships evolve | map + inventory + diary overlays; recurring motif |
| **"Would you survive?"** | scenario → 2–3 decisions with timers → outcome → autopsy | decision forks, rule cards, stats at end |
| **How to survive (educational)** | zombie-rule frame + real survival facts | rule cards, cutaway diagrams, calm narrator, accuracy first |
| **Last stand / siege** | one location, waves, resources vs time | floor-plan cutaway, noise rings, barricade stress meter |
| **Supply run** | plan → route → complication → escape | map route, inventory, CCTV cuts |
| **Mistake autopsy** | replay a failure; domino chain; "what went wrong" | slow-mo frames, arrows, red circles |
| **Mystery/Lore** | found documents, radio, hidden clues | diary, CCTV, flashbacks |
| **Base-building** | time-lapse, upgrades, cost | before/after splits, counters |
| **Group drama** | trust, betrayal, sacrifice | close-ups, quiet beats, split-screen |
| **Survival tips (Shorts)** | 1 tip + 1 scare in ≤ 45 s | one device, big text, quick hook |

## Length guides
Shorts 30–59 s: 1 hook, 1 rule, 1 escalation, 1 cliffhanger.
Mid 3–6 min: 2 peaks + quiet beat. Long 8–15 min: 3–4 peaks, midpoint twist, escalating stakes.

## Series bible (optional)
World rules (locked) · recurring characters · recurring location · running ledger · season arc · recurring ending hook ("Day X → ?").
